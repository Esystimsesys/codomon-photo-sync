# おむかえフォト 開発メモ

利用者向けの説明はすべて [README](../README.md) にまとめる。ここには、作りの判断と開発の手順だけを書く。

## 署名

Developer IDによる署名・Appleの公証は行わない。アプリ全体はアドホック署名する。署名がないと、ダウンロード後に「壊れているため開けません」と表示され、「プライバシーとセキュリティ」から許可することもできないため。Mac全体のGatekeeperを無効化する手順は案内しない。[Appleの説明](https://support.apple.com/ja-jp/102445)

## 仕様の補足

- 自動送信の対象は、自動送信をオンにした日（設定の`autoSendFrom`）以降にコドモンに届いた写真。届いた日は配信開始の日時（なければ投稿の日時）で判定する。園が記録に付けた日付はさかのぼることがあるため使わない。届いた日を記録していない古いデータは記録の日付で判定する。開始日のない古い設定は、その版を初めて開いた日を開始日にする。
- 送信ボタンを押した後に完了を確認できなかった写真は「確認が必要」にし、自動で再送しない。
- 「写真」アプリの個別の取り込み警告は、ほかの写真の送信を妨げない。顔解析全体が失敗した場合は、古い自動判定で送らない。
- コドモンの取り込みは、通信を試みた時点で回数に数える。再起動や時刻の変更では戻さず、Macの暦日が変わると0回に戻す。
- 「写真」アプリへの取り込みは、取り込み先のアルバムにある写真のファイル名で取り込み済みかを判定する。
- コドモンの動画（お知らせに付く）は、写真と同じ扱いにする（写真の一覧・「写真」アプリへの取り込み・顔認識・みてねの送信）。コドモンで変換が済み再生用URLがあるものだけ、配信（HLS・MPEG-TS）を取得してmacOS付属の`avconvert`で再エンコードせずMP4にし、投稿日を動画の作成日時に書き込む。暗号化された配信は保存しない。ファイル名は元の名前とサイズ（例：`IMG_0665-130077733.mp4`）で、園が期間を延長して再掲しても同じ動画として扱い、最初に保存した場所を使う（`.video-sources`）。一覧の画像はコドモンのサムネイルを`.video-thumbnails`に保存し、なければ仮の画像を出す。保存できなかった動画も、ファイル名・サイズ・再生期限を記録に残す。みてねはPCアップローダーで1本10分までなので（[公式ヘルプ](https://help.family-album.com/hc/ja/articles/360038720993)）、10分を超える動画は送らず、自動送信では結果の文に本数を出し、手動で選んだときは理由を示して止める。

## データの保存

- 写真・添付・記録：設定した保存先。記録は`日付/記録/<投稿識別子>.json`と`.md`に保存する。投稿単位のため、一部の取得失敗で別施設・別月の既存記録を消さない。
- 写真の日付：投稿日をEXIFへ書き込む。日付が不明な画像は原本を`unknown-date`へ保存し、「写真」アプリへの自動取り込みを保留する。
- 設定・写真の状態・送信台帳：Electronの`userData`配下`archive.sqlite`。
- ログイン状態：`userData/sessions/*.enc`。Electron safeStorage（MacではKeychain）で暗号化する。パスワードそのものは保存しない。暗号化が使えない場合は平文保存せずエラーにする。
- みてねのログイン状態は、連携が有効なとき、選別の更新で1日1回確認・更新する。
- 写真ライブラリDBは読み取り専用で開き、WALを含む最新状態を参照する。顔認識は非公開のDB形式に依存するため、OSの更新で対応が必要になることがある。
- 移行用ファイル（設定の「別のMacへ移す」）は、設定・送信台帳・手動の選択をJSONにしたもの。ログイン状態は含めない。読み込み先のMacの記録を優先して統合する。

## 開発・試験

```bash
cd desktop
npm ci
npm run browser:install
npm run typecheck
npm test
npm run test:ui
npm run test:native
npm start
```

`npm run demo`は隔離された一時データでElectronを起動する。`npm run dev -- --port 4179`は架空データだけのブラウザプレビュー。どちらもコドモン・みてねへの実送信はしない。実アプリの操作はpreloadの限定APIからメインプロセスへ渡し、レンダラーのNodeアクセス・任意ナビゲーション・任意IPCは許可しない。

## 配布ファイル

```bash
npm run package:mac
```

`desktop/release/`へDMGとZIPが生成される。Playwright用ブラウザを同梱するためサイズは大きめ。

`.github/workflows/desktop.yml`はApple SiliconとIntelの各Macランナーで試験・パッケージを作る。`v0.1.1`のようなタグを push すると、両方のDMG・ZIPを添付した下書きのGitHub Releaseまで作る。公開は下書きを確認してから手で行う。版番号の付け方と手順は[版番号とリリース](02-release.md)を参照。

署名・公証、完全自動更新、Windows版、iPhone管理は初版に含めない。更新ボタンはGitHub Releasesの新しい版を確認し、ダウンロードページへ案内する。
