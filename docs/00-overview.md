# 概要

## 目的

保育園から配信される子どもの写真を、手作業のダウンロードなしで手元に集める。あわせて、写真だけでは失われてしまう文脈（その日の活動記録や連絡帳の本文）も保存する。

## 処理の流れ

1. コドモン保護者版（`parents.codmon.com`）にログインする（セッションが生きていれば省略）
2. 直近30日分のタイムラインを取得する
3. 写真をダウンロードし、投稿日ごとのフォルダに保存する（EXIF に投稿日時を書き込む）
4. 全種別の本文を `記録.md` / `posts.json` として保存する
5. 添付ファイル（PDF 等）を `添付/` へ保存する
6. 未取り込みの写真を写真.app のアルバム（既定「コドモン」）へ取り込む
7. 顔認識で指定した人物と識別された写真を、人物別アルバムへ反映する（[04-face-recognition.md](04-face-recognition.md)）
8. 人物別アルバムの写真のうち未送信のものを、みてねへ送る（[05-mitene.md](05-mitene.md)）

1〜7 は毎日 17:30 と 21:00、7〜8 は 1 日 4 回、launchd が実行する（[03-operations.md](03-operations.md#定期実行)）。取得方法と差分の判定は [01-architecture.md](01-architecture.md) にまとめている。

## 保存されるもの

```text
~/Pictures/codomon/2026-08-05/
├── 123456789-IMG_0001.jpeg
├── ...（写真7枚）
├── 添付/
│   └── 12345-8月月初のおたより.pdf
├── 記録.md
└── posts.json
```

### 記録.md

```markdown
# 2026-08-05 の記録

## [活動記録] 散歩　近所の公園

- 公開範囲: 参加者にのみ公開 / 配信: 2026-08-05 11:18:21

（本文）

### 写真 7枚
- ![](123456789-IMG_0001.jpeg)
```

画像リンクは同じフォルダの実ファイルを相対参照するため、Markdown ビューアで開けば本文と写真が一緒に表示される。

### posts.json

タイムライン API の生データ。`記録.md` に載せていない項目が将来必要になっても、取りこぼさないための保険。

## 対象と対象外

**園から届く情報はすべて保存する。** 退園すると過去のデータは参照できなくなるため、取捨選択しない。

| 種別 (`timeline_kind`) | 表示名 | 内容 | 本文フィールド |
| --- | --- | --- | --- |
| `comments` | 連絡帳 | 体温・食事・睡眠・家庭からの連絡 | `content` |
| `topics` | お知らせ | 園からの通知。PDF 等の添付を含む | `content` |
| `activities` | 活動記録 | その日の活動の本文と写真 | `overview` |
| `bills` | 請求情報 | 月々の請求明細 | 明細は `data` |

当初は写真の付く `activities` / `topics` だけを対象にしていたが、**連絡帳（446件）がまるごと抜けていた**。保存対象を「写真の有無」で決めたのが誤りだった。

### 添付ファイル

お知らせ等には `file_url`（PDF・Word）が付く。園だより・行事予定・感染症のお知らせなどで、**退園後は入手できなくなる**ため保存する。

配信元のホストによっては、**ステータス 200 が返るのに中身が HTML** のことがあるため、`content-type` を確かめてから保存している。日本語のファイル名は URL エンコードされているので、デコードして戻す。

### 対象外

「写真共有・販売」（購入が必要な写真）は取得しない。自動化が自動課金に直結するリスクを避けるため、関連エンドポイントには一切アクセスしない。

## 制約

- **画像は幅 500px が上限**。無料で閲覧できる範囲の仕様で、原寸は写真販売の購入でしか入手できない（[01-architecture.md](01-architecture.md#画像の解像度)）
- **30日より古い投稿は毎回の取得対象外**。過去分が必要なら、`CODOMON_DAYS=365 .venv/bin/python3 sync_photos.py` のように日数を一時的に増やして1回実行する
- 園が同じファイル名のまま写真を差し替えた場合は、更新に気づかない（内容ではなくファイル名で判定しているため）
