# codomon-photo-sync

保育園・幼稚園向けアプリ **[コドモン](https://www.codmon.com/)** に配信された自分の子どもの写真と記録を、macOS のローカルへ自動で保存するツールです。

さらに、**写真.app の顔認識**で自分の子どもが写った写真だけを抽出し、家族アルバム **[みてね](https://mitene.us/)** へ自動アップロードできます。

```text
コドモン ──> ローカル保存 ──> 写真.app ──> 顔認識で人物を抽出 ──> みてね
            (写真・記録・添付)   (iCloud同期)                  (自動アップロード)
```

## なぜ作ったか

コドモンに投稿された写真は、アプリ内でしか見られず、一枚ずつ手で保存する必要があります。退園すれば過去の記録ごと参照できなくなります。

このツールは、園から届く情報を**まるごと手元に残し**、家族と共有するところまでを自動化します。

## できること

| | 内容 |
| --- | --- |
| 写真の保存 | 投稿日ごとのフォルダへ。**EXIF に投稿日時を埋める**ので時系列で正しく並ぶ |
| 記録の保存 | 連絡帳・活動記録・お知らせ・請求情報の本文を Markdown と JSON で |
| 添付の保存 | 園だより・行事予定などの PDF・Word |
| 写真.app 連携 | アルバムへ自動取り込み。iCloud 写真経由で iPhone からも見られる |
| 人物の抽出 | 顔認識で特定の子どもだけを集めたアルバムを自動生成 |
| みてね連携 | 未アップロード分を自動送信（**みてねプレミアムが必要**） |

すべて**差分方式**で、既に処理済みのものは再取得・再送信しません。

## 動作環境

- macOS（写真.app と AppleScript を使うため必須）
- Python 3.11 以降
- コドモンの保護者アカウント
- みてね連携を使う場合は **みてねプレミアム**（ブラウザからのアップロードが有料機能のため）

## セットアップ

```bash
git clone <このリポジトリ>
cd codomon-photo-sync

# 1. 依存関係
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/playwright install chromium

# 2. 設定（子どもの名前・アルバム名など）
cp config.example.json config.json
$EDITOR config.json

# 3. コドモンの認証情報を Keychain に登録
#    値は入力せず、対話プロンプトで打つ（シェル履歴に残さないため）
security add-generic-password -a "$USER" -s codomon-photo-sync-user -w
security add-generic-password -a "$USER" -s codomon-photo-sync-pass -w

# 4. 動作確認
.venv/bin/python3 sync_photos.py
```

顔認識を使う場合は、**フルディスクアクセス**の付与が必要です（写真.app のライブラリDBを読むため）。システム設定 → プライバシーとセキュリティ → フルディスクアクセス で、実行元のターミナルを許可してください。

みてね連携の初期設定と定期実行の登録は [運用ドキュメント](docs/03-operations.md) を参照してください。

## 設定

`config.json` に個人に紐づく値をまとめています（Git 管理外）。

| キー | 内容 |
| --- | --- |
| `person` | 写真.app のピープルで付けた名前。この人物の写真だけを抽出する |
| `album` | 写真.app に作る全写真用アルバムの名前 |
| `person_album` | 人物別アルバムの名前（省略時は「アルバム名（人物名）」） |
| `save_root` | 写真と記録の保存先 |
| `days_to_check` | 毎回さかのぼる日数 |
| `mitene_scope` | みてねの公開範囲ボタンの表示名 |

## 保存されるもの

```text
~/Pictures/codomon/2026-08-05/
├── 142228753-IMG_0260.jpeg   写真（EXIF に投稿日時を埋めてある）
├── 添付/
│   └── 12345-8月のおたより.pdf
├── 記録.md                    連絡帳・活動記録・お知らせ・請求の本文
└── posts.json                 生データ
```

`記録.md` は写真への相対リンクを含むので、Markdown ビューアで開けば本文と写真を一緒に読めます。

## 定期実行

launchd で 2 つのジョブを動かします。

| ジョブ | 時刻 | 処理 |
| --- | --- | --- |
| `codomon-sync` | 17:30 | コドモンから取得 → 写真.app へ取り込み |
| `codomon-person` | 7:00 / 13:00 / 19:00 / 21:00 | 顔認識の反映 → みてねへアップロード |

写真.app の顔解析は取り込み直後には終わらず、Mac がアイドルのときに進みます（実測で最短 50 分、多くは数時間）。そのため人物の抽出だけを小刻みに走らせ、解析が終わり次第すぐ反映されるようにしています。

## 構成

| ファイル | 役割 |
| --- | --- |
| `sync_photos.py` | 本体。取得・記録保存・写真.app 取り込み |
| `export_person.py` | 顔認識で人物別アルバムを生成 |
| `mitene_upload.py` | みてねへ未アップロード分を送信 |
| `run_person_tasks.py` | 上 2 つをまとめて実行（1日4回のジョブ用） |
| `common.py` | 設定読み込み・排他ロック・アトミック書き込み |

## 制約と注意

**画像は 500px が上限です。** コドモンの無料閲覧で配信される画像の仕様で、回避できません。このため顔認識の識別率も **2 割程度**に留まります（顔の幅の中央値が 33px しかないため）。原寸は「写真共有・販売」の購入でのみ入手できます。

**コドモンの内部APIを利用しています。** 公開APIではないため、予告なく仕様が変わる可能性があります。利用規約に自動化を明示的に禁じる条項はありませんが、自分のアカウントで自分の子の記録を取得する用途に限って使ってください。

**みてねのログインは自動化していません。** reCAPTCHA と 2 要素認証があり、これを迂回する実装は運営の意思に反すると判断したためです。ログインだけ手動で行い、以降のアップロードを自動化しています。セッションはアクセスのたびに延長されるため、定期実行が動いていれば再ログインはほぼ不要です。
