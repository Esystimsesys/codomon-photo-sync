# おむかえフォト

保育園・幼稚園向けアプリ **[コドモン](https://www.codmon.com/)** に届く子どもの写真と園の記録を、自動でMacに保存するアプリです。必要ならMacの「写真」アプリに取り込み、家族アルバム **[みてね](https://mitene.us/)** へも送ります。コドモン・みてねの運営会社とは関係ありません。

```text
コドモン ──> Macに保存 ──> Macの「写真」アプリ ──> 顔認識で子どもを選ぶ ──> みてね
            (写真・記録・添付)  (iCloudでiPhoneにも)               (送信)
```

コドモンの写真はアプリの中でしか見られず、退園すると過去の記録ごと見られなくなります。園から届いたものをまるごと手元に残し、家族と共有するところまでを自動にします。

## できること

| | 内容 |
| --- | --- |
| 写真の保存 | 投稿日ごとのフォルダへ。投稿日時を写真に書き込むので、Macの「写真」アプリでも正しい日付に並ぶ |
| 園の記録 | 連絡帳・活動記録・お知らせ・請求の本文と添付ファイルを保存し、アプリで読める |
| Macの「写真」アプリへの取り込み | 専用のアルバムへ追加する（任意） |
| 子どもの写真を選ぶ | Macの「写真」アプリの顔認識で子どもが写った写真を候補にし、子どもごとのアルバムにまとめる。きょうだいにも対応（任意） |
| みてねへの送信 | 候補を確認してから、または自動で送る。一度送った写真は二度と送らない（任意） |
| 自動同期 | 時刻を設定できる（初期値は17:30・21:00）。手動操作も含め取り込みは1日2回まで。ウィンドウを閉じてもバックグラウンドで動く |

「写真共有・販売」（有料のアルバム）の写真は取得しません。意図しない購入につながらないよう、関連する画面やAPIには触れません。

## 必要なもの

- Mac（Apple Silicon または Intel）
- コドモンの保護者アカウント
- 顔認識を使う場合は、Macの「写真」アプリの「ピープル」で子どもに名前を付けておくこと
- みてねへ送る場合は、みてねの有料プラン「プレミアムFamily」または「プレミアムFamily Pro」（[公式プラン比較](https://mitene.us/premium)）。無料版・プレミアムOneは対象外

## はじめかた

はじめて使うときは、Macにいくつか「許可」を求められます。どれも、このアプリがMacの中で作業するための確認です。下の手順どおりに進めれば大丈夫です。

### 1. ダウンロードして、アプリケーションフォルダに入れる

1. [Releases](https://github.com/Esystimsesys/codomon-photo-sync/releases) を開き、「Assets」からお使いのMacのプロセッサに合った.dmgファイルをダウンロードします。アップルメニュー →「このMacについて」を開き、「チップ」または「プロセッサ」の欄を確認します。
   - 「チップ」に「Apple M…」と表示される場合： `arm64` のファイル
   - 「プロセッサ」に「Intel」と表示される場合： `x64` のファイル
2. ダウンロードしたファイルを開き、「おむかえフォト」のアイコンを右の「Applications」フォルダへドラッグします。
3. コピーが終わったら、アイコンと「Applications」フォルダが並んだウィンドウを閉じます。Finderのサイドバーに「おむかえフォト」で始まる名前の項目が残っているときは、横の取り出しボタン（⏏）を押します。ダウンロードした.dmgファイルは削除してかまいません。

### 2. はじめて開く（1回だけ許可が必要）

このアプリは、Appleによる安全性の確認（公証）を受けていません。そのため、はじめて開こうとすると、アプリは起動せず、「Appleは、"おむかえフォト"にMacに損害を与えたり、プライバシーを侵害する可能性のあるマルウェアが含まれていないことを検証できませんでした。」という警告が表示されます。次の手順で、このアプリを開けるように許可します。

1. Finderの「アプリケーション」から「おむかえフォト」をダブルクリックします。
2. 上の警告が表示されたら、**「完了」** を押して閉じます。「ゴミ箱に入れる」は押さないでください。
3. アップルメニュー →「システム設定」→ **「プライバシーとセキュリティ」** を開き、いちばん下までスクロールします。
4. 「"おむかえフォト"は開発元を確認できないため…」の横にある **「このまま開く」** を押します。
5. もう一度確認が出るので **「このまま開く」** を押し、Macのパスワード（またはTouch ID）で許可します。

以降はダブルクリックするだけで開けます。

> 「このまま開く」が見当たらないときは、もう一度アプリをダブルクリックして警告を出してから、設定を開き直してください。ボタンは警告が出てから1時間ほどしか表示されません。

### 3. はじめの設定

アプリが開くと「はじめの設定」が表示されます。上から順に進めます。

1. **コドモンにログイン**：ボタンを押すと、ログイン用の画面が別に開きます。いつもコドモンに入るときと同じように、メールアドレス・パスワード・認証コードを入れてください。入力した内容はこのアプリには保存されません。
2. **保存先**：写真と記録を保存するフォルダです。そのままでかまいません（「ピクチャ」の中の `codomon`）。
3. **Macの「写真」アプリ**（使う場合だけ）：「写真」アプリに取り込むと、iCloud写真でiPhoneからも見られます。子どもの名前を登録すると、顔認識で子どもが写った写真を選べます。名前は、「写真」アプリの「ピープル」（「ピープルとペット」）で付けた名前と同じにします。
4. **みてね**（使う場合だけ）：「みてねにログイン」で、みてねにもログインします。送り方は、はじめは **「確認してから送る」** がおすすめです。
5. 最後に **「はじめる」** を押し、ホームの **「今すぐ同期」** を押すと、コドモンの写真と記録の取り込みが始まります。

「写真」アプリ・みてねは、あとから「設定」でも設定できます。

### 4. 途中で出る確認と、押すボタン

使っているうちに、次のような確認が出ることがあります。どれも1回許可すれば、次からは出ません。

| いつ出るか | 表示される内容 | 押すボタン | 許可しないと |
| --- | --- | --- | --- |
| 最初の同期や送信のとき | 「おむかえフォト」がキーチェーンの機密情報（おむかえフォト Safe Storage）を使おうとしている、という確認 | Macのパスワードを入れて **「常に許可」** | コドモン・みてねのログインが毎回切れる |
| はじめて「写真」アプリに取り込むとき | 「おむかえフォト」が「写真」を制御しようとしている、という確認 | **「許可」** | 「写真」アプリに取り込めない |
| 顔認識を使うとき | 自動では出ません。設定の「許可の設定を開く」を押して、次の手順で許可します | （下の手順） | 子どもが写った写真を選べない |
| 同期が終わったとき | 通知を許可するかの確認 | **「許可」** | 同期の結果が通知されない（アプリの画面では見られます） |

**顔認識の許可（フルディスクアクセス）の手順**

1. アプリの「設定」→「Macの「写真」アプリ」にある **「許可の設定を開く」** を押します。
2. 「フルディスクアクセス」の一覧で、**おむかえフォト** のスイッチをオンにします。一覧にないときは、下の「＋」から「アプリケーション」の「おむかえフォト」を選んで追加します。
3. 「終了して再度開く」と出たら、そのボタンを押します。出ないときは、メニューバーの双葉のアイコンから「終了」して、アプリを開き直します。

### うまくいかないとき

- **「壊れているため開けません」と出る**：古い版のDMGです。Releasesから新しいDMGをダウンロードし直してください。
- **間違えて「許可しない」を押した**：システム設定 →「プライバシーとセキュリティ」で、あとから変えられます。「写真」アプリへの取り込みは「オートメーション」→「おむかえフォト」の「写真」をオン、顔認識は「フルディスクアクセス」の「おむかえフォト」をオンにします。
- **キーチェーンで「拒否」を押した**：次の同期のときにもう一度聞かれます。そのとき「常に許可」を押してください。ログインが切れた場合は、アプリの「設定」からログインし直します。
- **アプリを新しい版に入れ替えた後**：上の許可を、もう一度求められることがあります。同じように許可してください。

新しい版が出ると、アプリのホーム画面と通知でお知らせします。ダウンロードしたアプリで置き換えると更新でき、写真・記録・設定はそのまま引き継がれます。

使うMacを変えるときは、設定の「別のMacへ移す」で設定とみてねの送信記録を引き継げます。手順は[おむかえフォトの説明](docs/01-desktop.md#別のmacへ移す)を見てください。

## 制約と注意

- **画像の大きさは幅500pxまでです。** コドモンで無料で見られる画像の仕様です。顔が小さく写るため、顔認識で本人と見分けられるのは一部の写真に限られます。候補は手動で入れたり外したりできます。
- **コドモンの非公開の仕組み（内部API）を使っています。** コドモン側の変更で、予告なく動かなくなることがあります。自分のアカウントで、自分の子どもの記録を保存する用途に限って使ってください。
- ログイン画面・認証コード・不正ログイン対策は、人が操作します。パスワードはこのアプリに保存しません。

```bash
npm run typecheck && npm test && npm run test:ui && npm run test:native
npm run dev   # 架空データだけのブラウザプレビュー
```
