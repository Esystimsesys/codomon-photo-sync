# おむかえフォト

保育園・幼稚園向けアプリ **[コドモン](https://www.codmon.com/)** に届く子どもの写真と園の記録を、自動でMacに保存するアプリです。

保存した写真は、Macの「写真」アプリに自動で取り込めます。また、家族アルバム **[みてね](https://mitene.us/)** に送って、家族みんなで共有できます。
「みてね」に送る写真は、自分で選ぶほか、「写真」アプリの顔認識（ピープル）と連携して、子どもが写っている写真を自動で送信することもできます。

コドモン・みてねの運営会社とは関係ありません。

```text
コドモン ──> Macに保存 ──> Macの「写真」アプリ ──> 顔認識で子どもを選ぶ ──> みてね
            (写真・記録・添付)  (iCloudでiPhoneにも)               (送信)
```

## できること

- **写真・動画と記録をまるごと保存**：コドモンに届いた写真・動画と、連絡帳・活動記録・お知らせなどの記録を、日付ごとにMacへ保存します。動画はMP4で保存し、写真と同じように「写真」アプリへの取り込み・顔認識・みてねへの送信の対象になります（みてねに送れるのは1本10分までの動画です）。アプリの「園の記録」では、記録ごとに付いていた写真・動画・おたより（PDFなど）をまとめて見られます。写真を大きく表示すると、その日の記録へ移れます。
- **決まった時刻に自動で取り込み**：一度設定すれば、新しい写真と記録を毎日自動で取り込みます。
- **iPhoneでも見られる**：Macの「写真」アプリに取り込むので、iCloud写真を使っていればiPhoneやiPadからも見られます。園から届いた日付で並びます。
- **わが子の写真を自動で選ぶ**：「写真」アプリの顔認識で子どもが写った写真を選び、子どもごとのアルバムにまとめます。きょうだいにも対応しています。
- **みてねで家族と共有**：選んだ写真を家族アルバム「みてね」に送ります。確認してから送るか、自動で送るかを選べます。

## 必要なもの

- macOS 15（Sequoia）以降のMac
- コドモンの保護者アカウント
- 顔認識を使う場合は、Macの「写真」アプリの「ピープル」で子どもに名前を付けておくこと
- みてねへ送る場合は、みてねの有料プラン「プレミアムFamily」または「プレミアムFamily Pro」（[公式プラン比較](https://mitene.us/premium)）。無料版・プレミアムOneは対象外

ほかのソフトのインストールは不要です。

## はじめかた

### 1. ダウンロードして、アプリケーションフォルダに入れる

1. [Releases](https://github.com/Esystimsesys/codomon-photo-sync/releases) を開き、「Assets」からお使いのMacのプロセッサに合った.dmgファイルをダウンロードします。アップルメニュー →「このMacについて」を開き、「チップ」または「プロセッサ」の欄を確認します。
   - 「チップ」に「Apple M…」と表示される場合： `arm64` のファイル
   - 「プロセッサ」に「Intel」と表示される場合： `x64` のファイル
2. ダウンロードしたファイルを開き、「おむかえフォト」のアイコンを右の「Applications」フォルダへドラッグします。
3. コピーが終わったら、アイコンと「Applications」フォルダが並んだウィンドウを閉じます。Finderのサイドバーに「おむかえフォト」で始まる名前の項目が残っているときは、横の取り出しボタン（⏏）を押します。ダウンロードした.dmgファイルは削除してかまいません。

### 2. はじめて開く（開く許可が必要）

このアプリは、Appleによる安全性の確認（公証）を受けていません。そのため、はじめて開こうとすると、アプリは起動せず、「Appleは、"おむかえフォト"にMacに損害を与えたり、プライバシーを侵害する可能性のあるマルウェアが含まれていないことを検証できませんでした。」という警告が表示されます。次の手順で、このアプリを開けるように許可します。

1. Finderの「アプリケーション」から「おむかえフォト」をダブルクリックします。
2. 上の警告が表示されたら、**「完了」** を押して閉じます。「ゴミ箱に入れる」は押さないでください。
3. アップルメニュー →「システム設定」→ **「プライバシーとセキュリティ」** を開き、いちばん下までスクロールします。
4. 「"おむかえフォト"は開発元を確認できないため…」の横にある **「このまま開く」** を押します。
5. もう一度確認が出るので **「このまま開く」** を押し、Macのパスワード（またはTouch ID）で許可します。

以降はダブルクリックするだけで開けます。

> 「このまま開く」が見当たらないときは、もう一度アプリをダブルクリックして警告を出してから、設定を開き直してください。ボタンは警告が出てから1時間ほどしか表示されません。

### 3. はじめの設定

アプリが開くと「はじめの設定」が表示されます。上から順に進めます。

1. **コドモンにログイン**：ボタンを押すと、ログイン用の画面が別に開きます。いつもコドモンに入るときと同じように、メールアドレス・パスワード・認証コードを入れてください。入力した内容はこのアプリには保存されません。
2. **保存先**：写真と記録を保存するフォルダです。そのままでかまいません（「ピクチャ」の中の `codomon`）。
3. **自動同期**：「決まった時刻に自動で同期する」をオンにします。オフのままだと、ホームの「今すぐ同期」を押したときだけ取り込みます。あわせて「Macにログインしたときに起動する」をオンにしておくと、Macを再起動しても自動で動きます。
4. **Macの「写真」アプリ**（使う場合だけ）：「写真」アプリに取り込むと、iCloud写真でiPhoneからも見られます。子どもの名前を登録すると、顔認識で子どもが写った写真を選べます。名前は、「写真」アプリの「ピープル」（「ピープルとペット」）で付けた名前と同じにします。
5. **みてね**（使う場合だけ）：「みてねにログイン」で、みてねにもログインします。送り方は、はじめは **「確認してから送る」** がおすすめです。
6. 最後に **「はじめる」** を押し、ホームの **「今すぐ同期」** を押すと、コドモンの写真と記録の取り込みが始まります。

「写真」アプリ・みてねは、あとから「設定」でも設定できます。

### 4. 途中で出る確認と、押すボタン

利用中に次のような確認が出ることがあります。以下のとおり許可してください。

| いつ出るか | 表示される内容 | 押すボタン | 許可しない場合 |
| --- | --- | --- | --- |
| はじめて「写真」アプリに取り込むとき | 「おむかえフォト」が「写真」を制御しようとしている、という確認 | **「許可」** | 「写真」アプリに取り込めない |
| 顔認識の人物を設定して、はじめて同期するとき | 「"おむかえフォト"に写真ライブラリへのアクセスを許可しますか？」という確認 | **「フルアクセスを許可」**（「写真を選択」ではなく） | 子どもが写った写真を選べない |
| 同期が終わったとき | 通知を許可するかの確認 | **「許可」** | 同期の結果が通知されない（アプリの画面では見られます） |
| アプリを新しい版に入れ替えた後、最初の同期やログインのとき | 「おむかえフォト」がキーチェーンに含まれるキー "codomon-photo-desktop Safe Storage" へアクセスしようとしている、という確認 | Macのパスワードを入れて **「常に許可」** | 保存したログイン情報を開けない |

### うまくいかないとき

- **間違えて「許可しない」を押した**：システム設定 →「プライバシーとセキュリティ」で、あとから変えられます。「写真」アプリへの取り込みは「オートメーション」→「おむかえフォト」の「写真」をオン、顔認識は「写真」→「おむかえフォト」をフルアクセスにします。アプリの「設定」→「Macの「写真」アプリ」にある「許可の設定を開く」からも開けます。
- **アプリを新しい版に入れ替えた後**：起動の許可（「2. はじめて開く」と同じ手順）と、キーチェーンの「常に許可」が毎回必要です。「許可」を押した場合は、次にログイン情報を使うときにもう一度聞かれます。「写真」アプリの操作と写真ライブラリの許可は、そのまま引き継がれます。

## 使い方

### 同期

- 自動同期をオンにすると、決まった時刻にコドモンから新しい写真と記録を取り込みます。初期値は17:30と21:00で、設定の「自動同期」で変えられます。
- ウィンドウを閉じても、メニューバーの双葉のアイコンに残って動き続けます。終了するときは、アイコンのメニューの「終了」か ⌘Q を使います。
- Macの電源が切れている間やスリープ中は動きません。スリープから戻ると、取り込めなかった分をまとめて取り込みます。
- はじめての同期では、今月からさかのぼって記録のある期間を取り込み、記録のない月が1年続いたところで止めます。それより前の記録は、設定の「期間を指定して取り込む」で取り込めます。

### 写真を選んで、みてねに送る

送り方は、設定の「みてねへの送信」で選びます。

- **確認してから送る**（おすすめ）：写真画面で送りたい写真にチェックを付けて送ります。
- **自動で送る**：顔認識で選ばれた写真を、同期のたびに送ります。送るのは、自動で送る設定にした日以降にコドモンに届いた写真だけです。それより前の写真は、ホームと写真画面のお知らせから、見て送るか「送らない」にできます。

写真ごとに「送る」「送らない」（みてねを使わないときは「アルバムに入れる」「入れない」）を押すと、顔認識の結果より優先されます。「自動に戻す」で顔認識の結果に戻ります。きょうだいを登録すると、誰か一人でも写っている写真が選ばれ、子どもごとのアルバムにまとまります。「写真」アプリで顔の解析が終わっていない写真は「顔認識の結果を待っています」と表示され、解析が終わってから選ばれます。

ほかの方法ですでにみてねに送った写真は、写真画面の「すでにみてねに送った写真を登録する」で「送らない」にしておくと、二重に送りません。

送信の途中で通信が切れるなどして、届いたか分からない写真は、お知らせに出ます。自動では送り直さないので、みてねで確かめて「届いていた」「届いていない」「送らない」から選んでください。

### 保存される場所

- 写真と記録は、設定した保存先（初期値は「ピクチャ」の中の `codomon`）に、日付ごとのフォルダで保存されます。「保存先を開く」で開けます。
- 設定と、みてねに送った記録は、このMacの中だけに保存されます。開発者のサーバーなどに送られることはありません。
- おむかえフォトを削除しても、保存した写真と記録は消えません。

## アップデート

新しい版が出ると、アプリのホーム画面と通知でお知らせします。[Releases](https://github.com/Esystimsesys/codomon-photo-sync/releases) から新しいDMGをダウンロードし、「アプリケーション」フォルダのアプリと置き換えると更新できます。写真・記録・設定はそのまま引き継がれます。

## 別のMacへ移す

使うMacを変えるときは、設定の「別のMacへ移す」で移行用ファイルを受け渡します。引き継ぐのは、設定、みてねに送った（送らないことにした）記録、手動で選んだ・外した写真です。ログイン情報は引き継がないので、新しいMacでログインし直します。写真と記録は、新しいMacで同期すると取り込み直します。

1. **前のMac**：設定 →「別のMacへ移す」→ **「移行用ファイルを書き出す」** を押します。二重に動かないよう、このMacの自動同期とログイン時の起動はオフになります。書き出したら、メニューバーの双葉のアイコンから「終了」します。
2. 書き出したファイルを、AirDropやiCloud Driveなどで新しいMacへ移します。
3. **新しいMac**：iCloud写真を使っている場合は、「写真」アプリに取り込み先のアルバム（初期値は「コドモン」）が届くまで待ちます。届く前に同期すると、同じ写真が「写真」アプリに二重に入ることがあります。
4. おむかえフォトを入れて開き、「はじめの設定」の **「移行用ファイルを読み込む」** で読み込みます。
5. 「はじめかた」と同じように、コドモン・みてねへのログインと許可を済ませ、「はじめる」→「今すぐ同期」を押します。
6. 新しいMacで同期と送信ができたことを確かめてから、前のMacのおむかえフォトを削除します。

新しいMacをすでに使いはじめていても、あとから設定の「別のMacへ移す」で読み込めます。新しいMacで送った写真や手動で選んだ写真は、読み込んでも変わりません。

## 制約と注意

- **画像の大きさは幅500pxまでです。** コドモンで無料で見られる画像の仕様です。顔が小さく写るため、顔認識で本人と見分けられるのは一部の写真に限られます。候補は手動で入れたり外したりできます。
- **コドモンの非公開の仕組み（内部API）を使っています。** コドモン側の変更で、予告なく動かなくなることがあります。自分のアカウントで、自分の子どもの記録を保存する用途に限って使ってください。
- ログイン画面・認証コード・不正ログイン対策は、人が操作します。パスワードはこのアプリに保存しません。
- **コドモンからの取り込みは1日2回までです。** 「今すぐ同期」や期間を指定した取り込みも含みます。途中で失敗しても1回と数え、日付が変わると戻ります。ただし、最初のログインの確認で止まったとき（ログインが切れている、コドモンが止まっている）は数えないので、ログインし直せばその日のうちに同期できます。コドモンに負担をかけないための制限です。
- 「写真共有・販売」（有料のアルバム）の写真は取得しません。意図しない購入につながらないよう、関連する画面には触れません。
- Intel の Mac 向け（`x64`）は、自動テストでの確認だけで公開しています。
