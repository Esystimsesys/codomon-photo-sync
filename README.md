# codomon-photo-sync

保育園・幼稚園向けアプリ **[コドモン](https://www.codmon.com/)** に届く子どもの写真と記録を、Mac へ自動で保存するツールです。

写真は写真.app のアルバムにも取り込むので、iCloud 写真を使っていれば iPhone からも見られます。さらに、写真.app の**顔認識**で自分の子どもが写った写真だけを選び、家族アルバム **[みてね](https://mitene.us/)** へ自動でアップロードすることもできます。

```text
コドモン ──> Mac に保存 ──> 写真.app ──> 顔認識で子どもを選ぶ ──> みてね
            (写真・記録・添付)  (iCloud で iPhone にも)              (自動アップロード)
```

## なぜ作ったか

コドモンの写真はアプリの中でしか見られず、残すには一枚ずつ手で保存するしかありません。退園すると、過去の記録ごと見られなくなります。

このツールは、園から届いたものを**まるごと手元に残し**、家族と共有するところまでを自動にします。

## できること

| | 内容 |
| --- | --- |
| 写真の保存 | 投稿日ごとのフォルダへ。投稿日時を写真に書き込むので、写真.app でも正しい日付に並ぶ |
| 記録の保存 | 連絡帳・活動記録・お知らせ・請求情報の本文 |
| 添付の保存 | 園だより・行事予定などの PDF や Word |
| 写真.app への取り込み | 専用のアルバムへ自動で追加 |
| 子どもの写真だけを選ぶ | 顔認識で、自分の子どもが写った写真のアルバムを自動で作る（任意） |
| みてねへの送信 | 選んだ写真のうち、まだ送っていないものを自動で送る（任意・**みてねプレミアムが必要**） |

一度保存・送信したものは二度と取りに行かず、二重にも送りません。

**「写真共有・販売」（有料のアルバム）の写真は取得しません。** 購入が必要な機能なので、自動化すると意図しない購入につながるおそれがあり、関連する画面や API には一切アクセスしません。必要な写真はコドモン上で購入・保存し、写真.app の同じアルバムへ入れてください。顔認識とみてねへの送信はそのまま働きます。

## 必要なもの

- Mac（写真.app と AppleScript を使うため、macOS 専用です）
- コドモンの保護者アカウント
- 1GB ほどの空き容量（自動操作用のブラウザ Chromium 約 550MB を含みます）
- みてねへ送る場合は、みてねプレミアム（Web からのアップロードが有料プランの機能のため）

Python 3.11 以降も必要ですが、入れ方は下の手順で説明します。

## セットアップ

ターミナル（「アプリケーション」→「ユーティリティ」→「ターミナル」）を開き、順にコマンドを貼り付けて実行します。所要時間は 10〜20 分で、ほとんどはダウンロードの待ち時間です。

### 1. Python を用意する

まず、今の Python の版を確認します。

```bash
python3 -V
```

`Python 3.11` 以上と出たら、この手順は飛ばしてください。

`Python 3.9.6` などと出たら、次の 2 行で新しい Python を入れます（管理者パスワードは不要です）。

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
~/.local/bin/uv python install 3.13
```

Homebrew を普段から使っている場合は、代わりに `brew install python@3.13` でも構いません。

入れたあとも `python3 -V` は 3.9 と表示されることがありますが、問題ありません。次の手順の `setup.py` が新しい Python を自動で見つけて使います。

> 初めて `python3` や `git` を使う Mac では、「コマンドライン・デベロッパツール」のインストールを求めるダイアログが出ます。「インストール」を選び、完了したら同じコマンドをもう一度実行してください。

### 2. ダウンロードしてセットアップを実行する

```bash
cd ~
git clone https://github.com/Esystimsesys/codomon-photo-sync.git
cd codomon-photo-sync
python3 setup.py
```

ホームフォルダ（`cd ~`）に置くのは、「書類」や「デスクトップ」が iCloud Drive で同期されている場合に、ログイン情報を含むファイルまで同期されるのを避けるためです。

`python3 setup.py` を実行するとメニューが出るので、`1`（初期セットアップ）を選びます。あとは画面の質問に答えるだけで、次のことがまとめて終わります。設定ファイルを手で書き換える必要はありません。

- ツールが使う部品とブラウザ（Chromium）のダウンロード
- 写真の保存先・アルバム名などの設定
- コドモンのメールアドレスとパスワードの登録
- 1 日数回の自動実行の登録

メールアドレスとパスワードは、入力しても画面に表示されません。Mac の「キーチェーン」に暗号化して保存され、ファイルには書き出されません（詳しくは [セキュリティ](docs/02-security.md)）。

最後に「いま初回の取得を実行しますか？」と聞かれたら、Enter で実行します。

### 3. 最初に出る確認ダイアログを許可する

初回の取得や自動実行のときに、macOS の確認ダイアログが出ることがあります。

| ダイアログ | 押すボタン |
| --- | --- |
| 「"写真"を制御するアクセスを求めています」 | **OK** |
| キーチェーンへのアクセスの確認 | **常に許可**（「許可」だと毎回聞かれ、無人の自動実行が止まります） |

ここまでで、写真と記録の保存・写真.app への取り込みが毎日自動で行われます。

## 子どもの写真だけを選ぶ（任意）

顔認識を使うと、自分の子どもが写った写真だけを集めたアルバム（例: 「コドモン（たろう）」）を自動で作れます。みてねへ送るのもこのアルバムの写真です。

1. **写真.app で子どもに名前を付ける**
   写真.app の「ピープル」（macOS によっては「ピープルとペット」）で子どもの顔を選び、名前を付けます。
2. **その名前をツールに登録する**
   `python3 setup.py` → `1` を選び直し、「子どもの名前」に**写真.app と同じ表記**で入力します。ほかの質問は Enter でそのまま進められます。
3. **フルディスクアクセスを許可する**
   顔認識の結果を読むために必要です。macOS の仕様で、この操作だけは自動化できません。
   「システム設定」→「プライバシーとセキュリティ」→「フルディスクアクセス」を開き、ターミナルをオンにします。オンにしたら、ターミナルを一度終了して開き直してください。

最後に `python3 setup.py doctor` を実行し、「人物」と「フルディスクアクセス」に ✓ が付けば完了です。

写真.app の顔の解析は、取り込んだ直後ではなく Mac を使っていないときに少しずつ進みます。新しい写真がアルバムに入るまで、数時間から 1 日ほどかかります。

## みてねへ自動で送る（任意）

前の「子どもの写真だけを選ぶ」を済ませてから、次を実行します。

```bash
python3 setup.py mitene
```

ブラウザ（「Google Chrome for Testing」という名前で開きます）でみてねにログインし、届いた確認コードも入力してください。ログインできたら自動で閉じます。ログインだけは、みてねの不正ログイン対策（reCAPTCHA と確認コード）があるため手で行う仕組みにしています。

最後に「今ある写真を送らずにおきますか？」と聞かれます。

- **はい**: 今ある写真は送らず、これから届く写真だけを送ります。みてねへ手作業で上げてきた写真と二重になりません。
- **いいえ**: 今ある写真も、次の自動実行でまとめて送ります。

ログインは自動実行のたびに延長されるので、普段は再ログインの必要はありません。Mac を 2 週間以上使わなかったときなどにログインが切れると、通知が届きます。そのときは同じ `python3 setup.py mitene` を実行してください。送れなかった写真は、再ログイン後に自動で送られます。

## うまくいかないとき

まず次のコマンドで状態を確認してください。足りないものと直し方が表示されます。

```bash
python3 setup.py doctor
```

```text
環境
  ✓ macOS 26.6.1
  ✓ Python 3.13.2
  ✓ 仮想環境と依存パッケージ
  ✓ Chromium

設定
  ✓ config.json
  ✓ コドモンの認証情報（Keychain）
  ✗ フルディスクアクセスがありません
     システム設定 → プライバシーとセキュリティ → フルディスクアクセス で
     setup.py を実行したアプリ（ターミナル / iTerm / VS Code など）をオンにし、
     そのアプリを一度終了して開き直してください
```

自動実行が止まったときは、Mac の通知でお知らせします（1 日 2 回、自動で点検しています）。

よくあるケース:

| 症状 | 対処 |
| --- | --- |
| Mac を再起動したあと動かない | 再起動後に一度ログインするまで、自動実行は動きません。ログインすれば次の時刻から再開します |
| 子どもの写真のアルバムが更新されない | `doctor` の「定期実行」の欄を確認してください。自動実行側にフルディスクアクセスが無い場合は、追加すべきファイルの場所が表示されます |
| みてねへの送信が止まった | `python3 setup.py mitene` で再ログインしてください |
| コドモンにログインできない | パスワードを変えた場合は、`python3 setup.py` → `1` を選び、「登録し直しますか？」に `y` と答えて入力し直してください |

詳しい原因と対処は [運用](docs/03-operations.md#トラブルシュート) にまとめています。

## そのほかの操作

```bash
python3 setup.py            # メニューを出す
python3 setup.py doctor     # 状態を確認する
python3 setup.py schedule   # 自動実行を登録し直す
python3 setup.py uninstall  # 自動実行を止めて、不要なものを削除する（→ アンインストール）
```

過去の写真をまとめて取り込みたいときは、さかのぼる日数を指定して一度だけ実行します。

```bash
CODOMON_DAYS=365 .venv/bin/python3 sync_photos.py
```

## アンインストール

### 1. 自動実行を止めて、ツールが作ったものを消す

```bash
cd ~/codomon-photo-sync
python3 setup.py uninstall
```

自動実行は必ず止まります。そのほかは、消すかどうかを一つずつ尋ねます。Enter だけで答えたときの扱いは次のとおりです。

| 質問 | Enter のとき | 内容 |
| --- | --- | --- |
| ログ | 消す | `~/Library/Logs/codomon-photo-sync` |
| セッション・台帳・設定 | 残す | ログイン状態、みてねの送信履歴、`config.json` など |
| Keychain の認証情報 | 残す | 登録したコドモンのメールアドレスとパスワード |
| 仮想環境 | 消す | ツールが使う部品（`.venv`） |
| 取得した写真と記録 | 残す | `~/Pictures/codomon` |

すべて消すときは、それぞれ `y` と答えてください。写真だけは既定で残します。コドモンから消えた古い投稿は、消すと二度と取得できないためです。必要なら、先に別の場所へ移してから消してください。

### 2. 残るものを手で消す（必要な場合）

`uninstall` では、次のものは消えません。

| 残るもの | 消し方 |
| --- | --- |
| 写真.app のアルバムと写真 | アルバムを削除しても、写真はライブラリに残ります。写真ごと消すときは、先にアルバムを開いて全選択（⌘A）し、削除してから、アルバムを削除します |
| ブラウザ Chromium（約 550MB） | ほかに Playwright を使うツールが無ければ `rm -rf ~/Library/Caches/ms-playwright` |
| フルディスクアクセスの許可 | 「システム設定」→「プライバシーとセキュリティ」→「フルディスクアクセス」で、追加した項目をオフにするか「−」で外します |
| このフォルダ | `rm -rf ~/codomon-photo-sync` |
| みてねへ送った写真 | みてね側に残ります。不要ならみてねのアプリで削除します |

セットアップのために uv と Python を入れ、ほかに使っていない場合は、次のコマンドで消せます。

```bash
~/.local/bin/uv python uninstall 3.13
rm ~/.local/bin/uv ~/.local/bin/uvx
```

## 保存されるもの

```text
~/Pictures/codomon/2026-08-05/
├── 123456789-IMG_0001.jpeg   写真（投稿日時を書き込み済み）
├── 添付/
│   └── 12345-8月のおたより.pdf
├── 記録.md                    連絡帳・活動記録・お知らせ・請求の本文
└── posts.json                 コドモンから受け取ったままのデータ
```

`記録.md` には写真へのリンクが入っているので、Markdown ビューアで開くと本文と写真を一緒に読めます。

## 設定

設定は `config.json` にあり、`setup.py` が作ります。あとから変えたいときだけ、テキストエディタで直接編集してください。

| キー | 内容 |
| --- | --- |
| `person` | 写真.app の「ピープル」で付けた子どもの名前。空なら顔認識を使わない |
| `album` | 写真.app に作るアルバムの名前（既定「コドモン」） |
| `person_album` | 子どもの写真のアルバム名（`null` なら「アルバム名（子どもの名前）」） |
| `save_root` | 写真と記録の保存先（既定 `~/Pictures/codomon`） |
| `days_to_check` | 毎回さかのぼる日数（既定 30） |
| `mitene_scope` | みてねの公開範囲（既定「家族みんなに公開」） |
| `face_min_px` ほか `face_*` | 子どもの写真を選ぶ基準。通常は変更不要（[顔認識](docs/04-face-recognition.md#顔の大きさと主役度で絞る)） |
| `job_labels` | 自動実行の点検対象。`setup.py` が書くので触らない |

## 自動実行のスケジュール

| 処理 | 時刻 |
| --- | --- |
| コドモンから取得し、写真.app へ取り込む | 17:30 / 21:00 |
| 子どもの写真のアルバムを更新し、みてねへ送る | 7:00 / 13:00 / 19:00 / 22:00 |
| 上の 2 つが止まっていないか点検し、異常なら通知する | 8:00 / 23:00 |

Mac がスリープしていた場合は、次に起きたときに実行されます。時刻を決めた理由は [運用](docs/03-operations.md#定期実行) にあります。

## 制約と注意

**画像の大きさは幅 500px までです。** コドモンで無料で見られる画像の仕様で、変えられません。顔が小さく写るため、顔認識で本人と見分けられるのは全体の 2 割ほどの写真に限られます。

**コドモンの非公開の仕組み（内部 API）を使っています。** コドモン側の変更で、予告なく動かなくなることがあります。自分のアカウントで、自分の子どもの記録を保存する用途に限って使ってください。

## 開発者向け

| ファイル | 役割 |
| --- | --- |
| `setup.py` | 導入・設定・撤去。これだけはシステムの python3（3.9）でも動く |
| `sync_photos.py` | コドモンからの取得、記録の保存、写真.app への取り込み |
| `export_person.py` | 顔認識で子どもの写真のアルバムを作る |
| `mitene_upload.py` | みてねへ未送信の写真を送る |
| `run_person_tasks.py` | 上の 2 つをまとめて実行する（1 日 4 回のジョブ用） |
| `common.py` | 設定の読み込み・排他ロック・安全な書き込み・人物の判定（アルバムとみてねで共通） |
| `healthcheck.py` | 自動実行が止まっていないかを点検し、異常なら通知する |

テストは一時ディレクトリとモックを使い、コドモン・みてねへの通信、写真.app の変更、launchd への登録を行いません。

```bash
.venv/bin/python -m unittest discover -s tests -v
```
